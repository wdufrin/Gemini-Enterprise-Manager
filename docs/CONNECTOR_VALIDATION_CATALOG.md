## How to Update or Add a Connector Checklist

1. Open the corresponding domain file in `components/connectors/checklist/catalog/`:
   - `components/connectors/checklist/catalog/google-cloud-workspace.json`
   - `components/connectors/checklist/catalog/microsoft-enterprise.json`
   - `components/connectors/checklist/catalog/atlassian-devtools.json`
   - `components/connectors/checklist/catalog/crm-itsm-erp.json`
   - `components/connectors/checklist/catalog/collaboration-productivity.json`
2. Add or update the connector entry following `checklist.schema.json`.
3. Run `node scripts/syncChecklists.mjs` to validate the schema and regenerate this reference table.
